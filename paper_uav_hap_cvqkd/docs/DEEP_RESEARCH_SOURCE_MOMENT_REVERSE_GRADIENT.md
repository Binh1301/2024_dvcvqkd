# Deep research: full-support reverse gradients for adaptive 256-state DM-CV-QKD

This report answers the current numerical and mathematical blocker: how to
obtain a defensible and computationally practical reverse-mode gradient of
the full-support source moments \(C(p,\alpha)\) and \(w(p,\alpha)\) for
adaptive probabilistic shaping, geometric shaping, and modulation variance.
It is bound to the repository's current frozen model, corrected source
moments, C4 constrained forward tangent, and fail-closed lifecycle state.

The report distinguishes four evidence labels:

- **Literature-supported fact**: supported by an external source listed in
  the Sources section.
- **Mathematical derivation**: follows from the stated finite-dimensional
  equations and the real Frobenius pairing.
- **Numerical-analysis inference**: inferred from conditioning, residuals,
  convergence behavior, or measured runtimes.
- **Engineering recommendation**: a proposed implementation or gate, not a
  result already established by the repository.

## 1. System context

The project studies discrete-modulated continuous-variable quantum key
distribution over a HAP-to-UAV free-space optical fading channel. Alice
prepares \(M=256\) coherent states, Bob uses heterodyne detection, and
reverse reconciliation is used. The adaptive transmitter has three
families of variables:

1. probabilistic shaping (PS), which changes the state probabilities;
2. geometric shaping (GS), which changes the state locations; and
3. \(V_A\), which changes the physical modulation scale.

The statewise model is

\[
  K_n=\beta_{\rm rec}I_{AB,n}-\chi_{BE,n}^{\rm ub}.
\]

The Holevo term is evaluated over the full physically admissible correlation
interval, not at a single guessed correlation:

\[
  \chi_{BE,n}^{\rm ub}
  =\max_{Z\in[Z_{L,n},Z_{U,n}]}\chi_{BE,n}(Z).
\]

The physical channel and the forward full-\(Z\) evaluation are not the
current differentiability blocker. The blocker is a full-support derivative
of the source moments that is both mathematically faithful to the security
functional and fast enough to be used repeatedly by adaptive optimization.

The repository state at the time of this report is
NOT_READY_FOR_PUBLICATION_SCALE_RUNS and
NOT_READY_FOR_ADAPTIVE_TRAINING. No publication-scale training, final-test
access, optimizer step, or full reverse VJP is authorized by this report.

## 2. Adaptive 256-state constellation

There are 64 representatives and four C4 rotations. For representative
\(k\) and rotation \(r\in\{0,1,2,3\}\),

\[
  \alpha_{k,r}=s\,i^r z_k,\qquad
  p_{k,r}=\frac{q_k}{4},
\]

where \(q_k>0\), \(\sum_kq_k=1\), and \(s\) is the physical scale selected
from \(V_A\) and the shaped geometry. In a PS path \(q\) changes while
\(z\) is fixed; in a GS path \(z\) changes; in a \(V_A\) path the scale
changes. Consequently, \(C\) and \(w\) must be differentiated at every
adaptive state and cannot be treated as global constants.

The physical variance convention used by the project is

\[
  V_A=2\sum_i p_i|\alpha_i|^2.
\]

The C4 reduction is an exact change of representation for the frozen
ensemble. It is not an approximation and does not authorize dropping any
of the 256 full-support states.

## 3. Security source moments

Define the preparation operator

\[
  \tau=\sum_i p_i|\alpha_i\rangle\langle\alpha_i|.
\]

For the source-moment security bound, the relevant quantities are the
corrected \(C\) and \(w\) generated by the project's exact Gram/C4
construction. They enter the correlation endpoints in the project notation

\[
  Z_\pm=2\sqrt{T}\,C\ \pm\ \sqrt{2T\epsilon\,w}.
\]

The exact admissible interval is then intersected with the separately
implemented physical \(Z\) interval. The formulas above are the source
moment boundary; they are not a statement that the present project has
finite-key or composable security. The project currently treats the source
moment and full-\(Z\) path as an asymptotic, attack-class-scoped numerical
object pending author review of the complete physical/security alignment.

**Literature-supported fact.** Denys, Brown, and Leverrier give an explicit
asymptotic secret-key lower bound for arbitrary coherent-state modulation.
Their paper is directly relevant to a source-moment implementation and
explains why high-order discrete constellations are useful, but it does not
provide a reverse-mode gradient for this repository's adaptive C4
parameterization.[^1]

## 4. C4 block representation

The current isolated full-support representation uses the 64 representatives
and four Fourier sectors. Let \(D=\operatorname{diag}(z)\),
\(P=\operatorname{diag}(1/(2\sqrt q))\), and \(r=s-1\pmod 4\). Define

\[
 H_d[i,j]=\sqrt{q_iq_j}\exp\!\left[
 -\frac{|z_i|^2+|i^d z_j|^2}{2}
 +\overline{z_i}\,i^d z_j
 \right].
\]

The sector blocks and their positive square roots are

\[
 X_s=\sum_{d=0}^{3}i^{sd}H_d,\qquad
 G_s=\frac{X_s+X_s^H}{2},\qquad
 S_s=G_s^{1/2}.
\]

The exact constrained matrices are defined by

\[
  B_sS_r=S_sD,\qquad
  A_sG_r=G_sD.
\]

The remaining forward graph is

\[
  Q_s=S_sP,\qquad T_s=A_sQ_r,
\]

\[
  u_k=\sum_{s,i}\overline{Q_s[i,k]}T_s[i,k],
  \qquad U=\operatorname{diag}(u),
  \qquad E_s=T_s-Q_sU,
\]

\[
  C=\sum_s\operatorname{Re}\operatorname{Tr}
       (S_sB_sS_rB_s^H),
  \qquad
  w=\sum_{s,k}4q_k\|E_s[:,k]\|_2^2.
\]

The current corrected definition retains complex \(u_k\) and weights the
residual columns by \(4q_k\). A real-part projection of \(u\), an unweighted
residual, a support threshold, a pseudoinverse, or an identity jitter would
change the functional under study.

## 6. Extreme Gram conditioning

At the target ensemble the smallest Gram eigenvalue was

\[
  \lambda_{\min}(G)=
  3.9730108272405810054\times10^{-618}.
\]

The corresponding square-root eigenvalue is approximately
\(1.9932\times10^{-309}\). Thus the worst spectral scales relevant to
unregularized full support include

\[
  \|G^{-1}\|_2\sim 2.52\times10^{617},\qquad
  \|G^{-1/2}\|_2\sim 5.02\times10^{308},
\]

and the smallest denominator in the square-root Fréchet solve can be
\(2\sqrt{\lambda_{\min}}\), whose inverse is approximately
\(2.51\times10^{308}\).

These are worst-case spectral scales, not predictions of every final
observable. The measured constrained \(A_s\) matrices reached only about
\(10^{69}\) in the target diagnostic, showing that structure and
cancellation matter. They do not prove that the cancellation is uniformly
stable throughout the adaptive domain.

**Numerical-analysis inference.** Resolving a nonzero eigenvalue at
\(10^{-618}\) against order-one entries requires substantially more than
618 reliable decimal digits if the computation must also survive
factorization, square-root, inverse-action, and observable cancellations.
The existing 800-digit result has approximately 182 decimal digits beyond
that scale and delivered residuals near \(10^{-799}\), but 800 digits is an
empirical local setting, not a global theorem.

## 8. Old reverse-mode failure

The old custom backward was an uncontrolled AP reverse implementation. It
was stopped after a bounded PS target mismatch spanning roughly 105 orders
of magnitude in the scalar directional derivative. Its status remains
AP_CUSTOM_BACKWARD_NOT_VALIDATED.

The most likely failure classes are:

- wrong complex conjugation or transpose in an adjoint;
- differentiating an explicit inverse rather than the actual constrained
  solve graph;
- missing shared-sector accumulation;
- omission of the complex \(u\) contribution in \(w\);
- insufficient precision after inverse-spectrum amplification; or
- a mathematically correct but numerically unusable reverse expression.

The corrected constrained formulation addresses the first structural risk by
making the implicit equations explicit and solve-based. Only independent
inner-product tests and a target VJP comparison can decide whether it fixes
the observed failure.

## 9. Major new result: exact constrained forward tangent

For a physical path \(\theta\mapsto(q(\theta),z(\theta))\), differentiate
the equations instead of differentiating a materialized inverse:

\[
  dS_s\,S_s+S_s\,dS_s=dG_s,
\]

\[
  dB_s\,S_r=B_s(-dS_r)+dS_sD+S_s\,dD,
\]

\[
  dA_s\,G_r=A_s(-dG_r)+dG_sD+G_s\,dD.
\]

Then

\[
  dQ_s=dS_sP+S_s\,dP,\qquad
  dT_s=dA_sQ_r+A_s\,dQ_r.
\]

The scalar residual and source moments follow by direct differentiation.
This is an exact tangent of the constrained forward graph, not a finite
difference and not a regularized derivative.

The implementation is intentionally isolated and marked
EXPERIMENTAL_DIAGNOSTIC_ONLY. It uses no explicit inverse or support
truncation in the constrained path.

## 11. Important interpretation

The forward tangent result answers a narrow mathematical question:

> For the tested target and four physical directions, the C4
> solve-constrained tangent agrees with corrected AP central differences
> while preserving full support.

It does not answer any of these stronger questions:

- whether the reverse adjoint has the same derivative convention;
- whether the derivative remains bounded in an adaptive neighborhood;
- whether a lower precision is safe away from the target;
- whether the full-Z maximizer has a differentiable active branch;
- whether the implementation can support a useful batch throughput; or
- whether a numerical result is a security certificate.

The next investigation must therefore preserve the exact source-moment
functional while separately testing algebra, conditioning, and throughput.

## 12. However, the exact tangent is too slow

The four target tangent directions consumed about 1.86 hours in aggregate,
with one direction taking nearly 48 minutes. This is acceptable as a rare
diagnostic oracle and unacceptable as the inner loop of adaptive
optimization.

The old custom backward took approximately 25653.39 seconds for its bounded
PS target attempt. It is not a useful performance baseline because it was
not validated, but it confirms that an unstructured Python/AP reverse is not
an obvious practical route.

A reverse VJP should be cheaper than four separate tangents because it
propagates one scalar objective backward through the graph. It still has to
evaluate the forward graph and solve the adjoint constrained systems. The
right comparison is therefore a measured compiled VJP against the current
forward tangent oracle, not an assumption that reverse mode removes
conditioning.

## 13. Large intermediates remain

Reverse mode reduces the number of parameter-direction solves, but it does
not remove the small eigenvalues. In particular:

- \(G_r^{-1}\) can have order \(10^{617}\) entries or operator norm in an
  unfavorable basis;
- the square-root adjoint has denominators as small as
  \(2\sqrt{\lambda_{\min}}\);
- the constrained \(A_s\) and its tangent can be much larger than the
  physical source moments;
- the final scalar can be benign because of cancellation, which makes
  guard precision more important rather than less important.

A correct reverse should avoid forming \(G^{-1}\) explicitly, but it cannot
avoid applying the inverse action represented by a solve. If a proposed
implementation reports small intermediates solely because it clips or
truncates the small spectrum, it is computing a different functional.

## 15. Current core problem

The required object is a VJP

\[
  \nabla_{q,z,V_A}\bigl(g_C C(q,z,V_A)+g_w w(q,z,V_A)\bigr),
\]

with arbitrary real upstream scalars \(g_C,g_w\), computed from the exact
full-support graph. The VJP must:

1. preserve the C4 probability and geometry manifold;
2. use the corrected complex \(u\) and weighted \(w\);
3. differentiate the positive square root and constrained solves exactly;
4. handle complex variables using a real scalar pairing;
5. expose solve/Sylvester residuals and support diagnostics;
6. converge under an explicit precision ladder; and
7. be fast enough that it can be benchmarked against the adaptive workload.

The numerical security claim remains separate: even a perfect source-moment
VJP is only an optimization primitive until the final candidate is
reevaluated by the approved forward security path.

## 16. Exact constrained system to reverse

The reverse should be the adjoint of this ordered computation:

1. build \(H_d\), Fourier-project to \(X_s\), and Hermitian-project to
   \(G_s\);
2. compute the principal positive square root \(S_s\);
3. solve \(B_sS_r=S_sD\) and \(A_sG_r=G_sD\);
4. form \(Q_s=S_sP\), \(T_s=A_sQ_r\), \(u\), and \(E_s\);
5. accumulate \(C\) and \(w\); and
6. map representative variables back to the C4 full ensemble and then to
   the PS/GS/\(V_A\) parameterization.

The crucial implementation choice is to treat the two constrained matrices
as outputs of right solves. The reverse of a right solve is another right
solve involving the conjugate-transposed coefficient. This is algebraically
equivalent to differentiating an inverse action, but it avoids materializing
an inverse and makes the residual test explicit.

The square-root map is a matrix-function node, not an elementwise square
root. Its tangent and adjoint are Sylvester equations. Replacing this node
by an elementwise operation or by a Cholesky factor without proving
functional equivalence would change the source moments.

## 17. Adjoint question: exact right-solve equations

Let the real Frobenius pairing be

\[
  \langle A,B\rangle=\operatorname{Re}\operatorname{Tr}(A^HB).
\]

For the generic right solve

\[
  XG=Y,
\]

the differential is

\[
  dX\,G+X\,dG=dY.
\]

Given an upstream \(\bar X\), define \(\bar Y\) by the adjoint right solve

\[
  \boxed{\ \bar Y\,G^H=\bar X\ }.
\]

Then the exact reverse updates are

\[
  \boxed{\ \bar G\mathrel{+}=-X^H\bar Y,\qquad
          \bar Y\text{ is accumulated upstream}\ }.
\]

This follows because

\[
  \langle\bar X,dX\rangle
  =\langle\bar Y,dY\rangle
   +\langle-X^H\bar Y,dG\rangle.
\]

For \(B_sS_r=S_sD\), set \(X=B_s\), \(G=S_r\), \(Y=S_sD\). Solve

\[
  \bar Y_{B,s}S_r^H=\bar B_s
\]

and accumulate

\[
  \bar S_r\mathrel{+}=-B_s^H\bar Y_{B,s},\qquad
  \bar S_s\mathrel{+}=\bar Y_{B,s}D^H,\qquad
  \bar D\mathrel{+}=S_s^H\bar Y_{B,s}.
\]

For \(A_sG_r=G_sD\), set \(X=A_s\), \(G=G_r\), \(Y=G_sD\). Solve

\[
  \bar Y_{A,s}G_r^H=\bar A_s
\]

and accumulate

\[
  \bar G_r\mathrel{+}=-A_s^H\bar Y_{A,s},\qquad
  \bar G_s\mathrel{+}=\bar Y_{A,s}D^H,\qquad
  \bar D\mathrel{+}=G_s^H\bar Y_{A,s}.
\]

These are the equations to implement. An LU factorization of \(S_r^H\) or
\(G_r^H\) may be reused if it is retained with enough precision, but
reusing a factorization does not remove the need to test the adjoint
residual. No explicit \(G_r^{-1}\) or \(S_r^{-1}\) should be formed.

**Mathematical derivation.** The equations are exact for arbitrary complex
matrices under the stated real pairing. They do not rely on a holomorphic
complex derivative and therefore apply to the real scalar \(C\) or \(w\).

## 18. Sylvester adjoint

The principal square root satisfies

\[
  S_s^2=G_s,\qquad S_s=S_s^H\succ0.
\]

Its forward differential is the Sylvester equation

\[
  \mathcal L_{S_s}(dS_s)
  :=S_s\,dS_s+dS_s\,S_s=dG_s.
\]

For Hermitian perturbations, \(dS_s\) and \(dG_s\) are Hermitian. Under the
real Frobenius pairing,

\[
  \langle A,SX+XS\rangle
  =\langle SA+AS,X\rangle
\]

when \(S=S^H\). Thus the Sylvester operator is self-adjoint on the
Hermitian subspace. Given \(\bar S_s\), first take its Hermitian projection
\(\mathcal H(\bar S_s)=(\bar S_s+\bar S_s^H)/2\), and solve

\[
  \boxed{\ S_s\bar G_s+\bar G_sS_s=\mathcal H(\bar S_s)\ }.
\]

Then pass \(\bar G_s\) through the Hermitian projection node:

\[
  \bar X_s\mathrel{+}=\mathcal H(\bar G_s).
\]

There is no extra factor of two. In the scalar case the equation is
\(2\sqrt g\,\bar g=\bar s\), exactly matching
\(ds=dg/(2\sqrt g)\). In an eigenbasis of \(G_s\), the adjoint entries are

\[
  (\bar G_s)_{ij}
  =\frac{\mathcal H(\bar S_s)_{ij}}
  {\sqrt{\lambda_i}+\sqrt{\lambda_j}}.
\]

**Literature-supported fact.** The Fréchet derivative of the positive
matrix square root is characterized by this unique Sylvester/Lyapunov
solution, and Taylor remainder bounds depend on the positive spectral
gap.[^8][^9][^10]

The same equation should be used for the forward root tangent and the
reverse root adjoint. A Schur or eigensolver may be used internally, but the
external contract remains a Sylvester residual and a Hermitian residual.

## 19. Complex differentiation

The objective is real, but the intermediates \(H_d,X_s,B_s,A_s,Q_s,T_s,u\)
are complex. The safe convention is to represent every complex matrix as a
real vector space and use

\[
  df=\operatorname{Re}\operatorname{Tr}(\bar X^HdX).
\]

For a complex scalar \(z=x+iy\), this is

\[
  df=\operatorname{Re}(\overline{\bar z}\,dz)
    =\operatorname{Re}(\bar z_{\mathbb R}\,dx
       +\bar z_{\mathbb I}\,dy)
\]

after identifying the real and imaginary components. The bar notation here
means a real-pairing gradient, not complex conjugation of the primal.

Three rules prevent the old class of errors:

1. the adjoint of right multiplication by \(G\) uses \(G^H\);
2. the adjoint of Hermitian projection is Hermitian projection; and
3. differentiation of a conjugate uses the real pairing, not a holomorphic
   assumption.

For the raw overlap, let \(\rho=i^d\) and

\[
  h=H_d[i,j],\qquad
  q=\overline{\bar h}\,h.
\]

With

\[
  a=-\frac{\overline{z_i}}2,\quad
  b=-\frac{z_i}{2}+\rho z_j,\quad
  c=-\frac{\overline{z_j}}2,\quad
  d_0=-\frac{z_j}{2}+\overline{z_i}\rho,
\]

the reverse contribution of this entry is

\[
  \bar q_i\mathrel{+}=\frac{\operatorname{Re}(q)}{2q_i},\qquad
  \bar q_j\mathrel{+}=\frac{\operatorname{Re}(q)}{2q_j},
\]

\[
  \bar z_i\mathrel{+}=(qa)^*+qb,\qquad
  \bar z_j\mathrel{+}=(qc)^*+qd_0.
\]

The symbol \(q\) is overloaded in the project between shaped probability
and this local scalar; production code should use distinct names such as
mass and overlap-cotangent to avoid a silent implementation error.

For the Fourier projection,

\[
  \bar H_d\mathrel{+}=\sum_s\overline{i^{sd}}\,\bar X_s.
\]

For the C4 map \(\alpha_{k,r}=i^rz_k\),

\[
  \bar z_k\mathrel{+}=\sum_{r=0}^{3}\overline{i^r}\,\bar\alpha_{k,r},
  \qquad
  \bar q_k\mathrel{+}=\frac14\sum_{r=0}^{3}\bar p_{k,r}.
\]

These formulas are ordinary real-adjoint formulas. Calling a library
complex gradient routine without checking which convention it uses is not
an independent validation.

For the physical parameter map, let \(g\) be an unconstrained geometry
vector, \(r^2=N^{-1}\sum_k|g_k|^2\), and \(x=g/r\). If \(\bar x\) is known,
then

\[
  \bar g_k=\frac{\bar x_k}{r}
  -\frac{\operatorname{Re}\sum_j\overline{\bar x_j}g_j}{Nr^3}\,g_k.
\]

If \(\alpha=sx\), \(s=\sqrt{V_A/(2E)}\), and
\(E=\sum_kq_k|x_k|^2\), define

\[
  \eta=s\,\operatorname{Re}\sum_k\overline{\bar\alpha_k}x_k.
\]

The exact reverse updates are

\[
  \bar x_k\mathrel{+}=s\bar\alpha_k-\frac{\eta q_k}{E}x_k,\qquad
  \bar q_k\mathrel{+}=-\frac{\eta|x_k|^2}{2E},\qquad
  \bar V_A\mathrel{+}=\frac{\eta}{2V_A}.
\]

For a softmax \(q_k=\exp(\ell_k)/\sum_j\exp(\ell_j)\),

\[
  \bar\ell_k=q_k\left(\bar q_k-\sum_jq_j\bar q_j\right).
\]

These normalization and manifold-chain rules are part of the VJP. A
reverse that stops at representative \(q,z\) is not yet a PS/GS/\(V_A\)
gradient.

## 20. Reverse-mode complexity

The exact reverse has one scalar VJP cost independent of the number of
optimization parameters, but it still has a substantial fixed graph cost.
Per four-sector target, the principal expensive operations are:

| operation | forward count | reverse count |
|---|---:|---:|
| \(64\times64\) constrained right solves for \(B_s,A_s\) | 8 | 8 adjoint right solves |
| square-root Sylvester solves | 4 tangents only when differentiating a direction | 4 adjoint solves |
| dense sector products and C4 Fourier maps | several | several |
| raw overlap entries | \(4\cdot64^2\) | same cached graph plus adjoint accumulation |
| parameter-direction solves | one set per tangent direction | none in a scalar VJP |

The reverse therefore replaces four or more parameter-direction solves by
one backward traversal, but it does not replace the eight inverse actions or
the four square-root inverse Fréchet actions.

The minimum useful forward cache contains \(H_d,X_s,G_s,S_s,A_s,B_s,Q_s,
T_s,u,E_s\), factorizations or equivalent solve data, and the C4 mapping
data. At 64 by 64, the mathematical storage is modest; at 1250--1650
decimal digits, Python object overhead and temporary allocation can dominate.
A contiguous compiled representation should fit comfortably below a
single-machine memory budget, but this is an engineering expectation and
must be measured rather than used as evidence.

The reverse accumulation for \(w\) is:

\[
  W=\operatorname{diag}(4q),\qquad
  \bar E_s=2g_wE_sW,\qquad
  \bar q_k\mathrel{+}=4g_w\sum_s\|E_s[:,k]\|_2^2.
\]

Then

\[
  \bar T_s\mathrel{+}=\bar E_s,\qquad
  \bar Q_s\mathrel{+}=-\bar E_sU^H.
\]

For the complex \(u\) node,

\[
  \bar u_k=-\sum_s Q_s[:,k]^H\bar E_s[:,k],
\]

\[
  \bar Q_s[:,k]\mathrel{+}=T_s[:,k]\overline{\bar u_k},\qquad
  \bar T_s[:,k]\mathrel{+}=Q_s[:,k]\bar u_k.
\]

Finally,

\[
  \bar A_s=\bar T_sQ_r^H,\qquad
  \bar Q_r\mathrel{+}=A_s^H\bar T_s,
\]

\[
  \bar S_s\mathrel{+}=\bar Q_sP^H,\qquad
  \bar P\mathrel{+}=S_s^H\bar Q_s.
\]

All sector contributions to a shared \(S_s,G_s,D\), and representative
probability, must be accumulated before mapping back to physical parameters.

For the direct \(C\) branch, write
\(c_s=\operatorname{Re}\operatorname{Tr}(S_sB_sS_rB_s^H)\). Its local
real-pairing reverse contributions are

\[
  \bar S_s\mathrel{+}=g_C\mathcal H(B_sS_rB_s^H),\qquad
  \bar S_r\mathrel{+}=g_C\mathcal H(B_s^HS_sB_s),
\]

\[
  \bar B_s\mathrel{+}=g_C\left(
      S_s^HB_sS_r^H+S_sB_sS_r\right).
\]

The two occurrences of \(S_s\) and \(S_r\) across neighboring sectors are
shared nodes, so these contributions must be accumulated before the
square-root adjoint is applied. With Hermitian \(S_s,S_r\), the first two
projections are already Hermitian up to roundoff and the \(B_s\) update is
the expected two-term derivative of a squared norm-like trace.

## 21. High-precision backend question

The backend has two distinct jobs:

1. a fast point-arithmetic engine for repeated exact objective/VJP
   experiments; and
2. a rigorous or independently checkable enclosure engine for certification.

One library need not be optimal for both jobs. The primary prototype should
therefore use C++17 with contiguous dense matrices and MPFR/MPC point
arithmetic. MPFR supplies arbitrary-precision real binary floating-point
with correct rounding; MPC supplies arbitrary-precision complex arithmetic
on top of MPFR.[^13][^14]

The implementation should keep the numerical kernels narrow:

- one precision-aware complex scalar wrapper;
- dense \(64\times64\) matrix multiply and adjoint;
- LU/triangular solve with pivot diagnostics;
- Hermitian eigensolver or Schur-based principal square root;
- Sylvester solve in a reused transformed basis;
- residual and inner-product reporting.

**Engineering recommendation.** Do not begin with a large autodiff or
tensor framework. The first compiled artifact should expose a scalar VJP
and primitive tests directly. That makes a failed identity attributable to
one equation and keeps the prototype small.

Julia BigFloat is a good research language for a readable reference, but it
wraps MPFR and does not by itself remove generic linear-algebra allocation or
dispatch overhead.[^15] Nemo provides useful Arb-based algebraic types and
can be a productive prototype, but a production timing claim still needs a
compiled-kernel benchmark.[^16]

## 22. Arb and ball arithmetic

Arb represents real numbers as midpoint-radius balls with rigorous
inclusion semantics. Its complex companion and FLINT's acb_mat provide
arbitrary-precision complex balls and dense matrix operations.[^11][^12][^19]

Ball arithmetic is valuable for:

- enclosing \(C\), \(w\), and source-moment derivatives;
- certifying residuals and positivity margins;
- detecting when a precision level is too low;
- adding an outward error budget to the \(Z\) interval and Holevo maximum.

It is not automatically a fast replacement for point arithmetic. Ball radii
can grow rapidly in ill-conditioned LU solves, especially when cancellation
is severe. The FLINT documentation also distinguishes approximate routines
that can be useful as preconditioners from rigorous ball computations. A
wide ball is a failed certification attempt, not permission to report its
midpoint.

The proposed use is hybrid:

1. MPFR/MPC point kernels for timing and repeated prototype VJPs;
2. Arb/acb_mat on selected target points and stress fixtures;
3. a precision-escalation rule that retries until all required balls are
   narrow enough or returns a fail-closed status.

For support, a ball eigensolver should not be the only test. A rigorous
positive-definiteness route can use an interval Cholesky/LDL factorization
with certified positive pivots, or a certified lower bound on the smallest
eigenvalue. Experimental eigenvector routines and midpoint eigenvalues are
diagnostics, not by themselves a publication certificate.

## 23. Required speedup

The current target tangent is measured, while the complete reverse runtime
is not. The earlier design study estimated an unstructured AP VJP at roughly
1200--10800 seconds per state; that range is a planning estimate, not a
measurement.

Relative to that estimate, the speedup needed is:

| target | required speedup from the estimate |
|---|---:|
| below 60 s/state | about 20--180x |
| below 10 s/state | about 120--1080x |
| about 1 s/state | about 1200--10800x |

Compilation can plausibly remove Python object and loop overhead, and C4
sector parallelism can reduce wall time. At thousands of decimal digits,
however, multiprecision arithmetic and dense \(O(64^3)\) kernels dominate.
The first factor may be tens-to-low hundreds in a favorable implementation;
the second is not a credible consequence of compilation alone.

**Numerical-analysis inference.** A compiled prototype can plausibly test a
sub-minute exact primitive or VJP, but the present evidence does not support
a claim of sub-10-second or one-second exact states. Those are benchmark
targets, not expected results.

## 24. Important exact reformulations

Several reformulations are worth testing because they preserve the security
functional if their derivatives are derived together with the change of
variables:

1. **Solve actions instead of inverses.** This is already the primary
   constrained representation and should be retained.
2. **Unitary eigenbasis for each Hermitian sector.** In that basis the
   principal square root and Sylvester denominators are explicit. The
   dense transforms and their adjoints must still be included.
3. **Exact basis changes or whitening.** A unitary basis preserves the
   Frobenius pairing directly. A nonunitary basis requires a transformed
   metric and can hide rather than remove conditioning.
4. **Exact row/column scaling and equilibration.** Scale the solve equations,
   transform right-hand sides and outputs, and reverse the scaling. Do not
   apply a scale to \(G\) and then call the square root of the scaled matrix
   the original \(S\); principal square roots do not commute with arbitrary
   diagonal congruences.
5. **Analytic cancellation in \(C\) and \(w\).** Use the defining
   constraints to remove redundant products only after proving equality and
   checking the VJP by an independent implementation.
6. **Coherent-state overlap identities.** Evaluate exponential differences
   with numerically stable elementary functions where possible, while
   retaining the exact overlap formula.
7. **Generalized eigen or polar formulations.** These may improve a kernel,
   but they introduce their own eigenvector/phase/conditioning derivatives
   and need a full equivalence proof.

Equilibration can reduce element growth and improve a particular
factorization. It cannot make a genuinely small singular value disappear,
and it cannot be credited as a precision reduction until a two-precision
experiment demonstrates it for the target family.

Projective or ratio coordinates are also not a free escape: the source
moment contains support-sensitive inverse actions, so a denominator that
looks harmless in one coordinate system may reappear in another.

## 25. Security-rigorous approximation

If exact gradients are too slow, the defensible approximation is an
optimization-only path with an explicit certification barrier:

1. use a lower-precision solve-based evaluation of the same \(C,w\)
   functional;
2. monitor solve, Sylvester, support, and normalization residuals;
3. use the resulting VJP only to propose parameters;
4. periodically re-evaluate candidates at high precision;
5. use outward value intervals for \(C,w\) and the full \(Z\) path before
   accepting any candidate; and
6. publish only the high-precision/ball-backed forward result.

A gradient approximation is not made security-rigorous by being close to a
finite difference. Security requires an outer bound on the value used in
the key-rate inequality. Pointwise AP agreement is excellent validation
evidence, but it is not an interval proof.

The best first approximation is therefore mixed precision and controlled
solver tolerance, not a learned surrogate. It preserves the exact graph and
makes the approximation error observable. Straight-through support
thresholds, clipped eigenvalues, or a differentiable pseudoinverse should
not be introduced as silent training conveniences.

## 26. Training versus certification separation

The lifecycle should have four explicit numerical roles:

| role | allowed computation | security meaning |
|---|---|---|
| optimization signal | approximate VJP of exact graph | no security claim |
| candidate screening | high-precision point forward | exploratory only until certified |
| candidate certification | ball or independently bounded \(C,w\), full physical \(Z\) interval, and Holevo maximum | supports the approved asymptotic claim if all other gates pass |
| publication evaluation | frozen protocol, frozen baselines, independent artifacts | lifecycle-gated |

A trained parameter vector must never inherit a certificate from the
approximate gradient path. The final candidate is a new numerical object.
The full \(Z\)-maximization also needs its own branch/optimizer error
control. Differentiating \(C\) and \(w\) does not certify a maximizer of
\(\chi_{BE}(Z)\), especially if the active maximizer changes branch.

The present repository remains closed at the first role: no adaptive
training is authorized while the reverse boundary is unvalidated and
impractical.

## 27. Possibility of surrogate gradients

Surrogate options can be ranked by how much of the exact graph they retain:

1. lower-precision exact constrained reverse;
2. mixed-precision exact reverse with high-precision solves at unstable
   nodes;
3. reverse of a locally interpolated \(C,w\) table;
4. a learned surrogate for \(C,w\); and
5. gradient-free optimization.

The first two are the only default recommendations. A table or learned
surrogate can be useful for exploration, but it needs domain coverage,
held-out error bounds, support guards, and an exact final reevaluation. A
small value error is not enough if it changes the maximizing \(Z\), the
sign of the key rate, or the chosen baseline.

Gradient-free search is attractive for a one-dimensional \(V_A\) sweep and
possibly a small calibration problem. It is not a practical replacement
for a 64-mass plus 128-real-coordinate adaptive problem without a strong
structure reduction.

## 28. Region-based AP calibration

An AP-calibrated approximation can be a useful engineering experiment if
it is labeled empirical:

1. define a bounded domain for positive masses, geometry, peak amplitude,
   and \(V_A\);
2. choose deterministic interior, boundary, near-coincident, and random
   seeded fixtures;
3. compute exact point values and VJPs at several precision levels;
4. compare the fast path with the high-precision path;
5. reserve a held-out set for error assessment; and
6. accept a proposed point only after exact forward re-evaluation.

The result can produce a conservative engineering guard such as
“reject if the observed discrepancy exceeds \(\delta\).” It cannot produce
a rigorous uniform bound over a continuous domain from finite samples.

For a uniform claim, combine interval/ball arithmetic with analytic bounds
on the domain, or derive Lipschitz/condition estimates that include the
smallest support eigenvalue, solve separation, square-root separation, and
the nonlinear \(Z\) and Holevo maps. Because those quantities can vary
sharply near coincident states, a region certificate should subdivide or
fail closed rather than extrapolate from the target.

## 29. Why not simply truncate tiny modes?

For a finite set of distinct coherent amplitudes, the coherent states are
linearly independent. A short proof is available without a numerical
assumption. If

\[
  \sum_{j=1}^{M}c_j|\alpha_j\rangle=0,
\]

then the Fock coefficients imply

\[
  \sum_{j=1}^{M}
  c_j e^{-|\alpha_j|^2/2}\alpha_j^n=0
  \quad\text{for every }n\geq0.
\]

Taking \(n=0,\ldots,M-1\) gives a Vandermonde system. Distinct
\(\alpha_j\) make it nonsingular, so every \(c_j=0\). Therefore the
mathematical Gram matrix is positive definite even when its smallest
eigenvalue is numerically tiny.[^17]

Discarding an eigenvalue below a threshold changes at least three things:

- the support of the source state;
- the inverse action in \(A_s\) and \(B_s\); and
- the derivative of the source-moment functional.

Replacing \(G^{-1}\) by a Moore--Penrose inverse after truncation is a
different definition. It can also be discontinuous when an eigenvalue
crosses the threshold, which makes its training gradient unsuitable as an
unannounced substitute for the security functional.

A rigorous approximation could be possible, but it needs a theorem that
connects the modified state and modified inverse actions to the security
quantity. For example, if an approximate state \(\widetilde\rho\) has a
certified trace-distance error, entropy continuity can bound a corresponding
security change. That does not automatically bound the present \(C,w\)
formula, because inverse and inverse-square-root actions are sensitive to
the support gap. A perturbation bound for an inverse contains the factor
\(\|G^{-1}\|^2\); here that factor can be about \(10^{1235}\).

Thus a threshold can be used only in a separate exploratory approximation
whose output is always re-evaluated by the exact full-support path. It is
not an acceptable silent repair of the current source moments.

## 30. Original security literature

The relevant literature has several distinct proof families.

**Literature-supported fact.** Denys, Brown, and Leverrier derive an
asymptotic analytical lower bound for arbitrary coherent-state modulation.
Their work is the closest literature match to the project's \(C,w\) source
moments and reports that sufficiently large discrete constellations can
approach Gaussian-modulation performance. Their ancillary QAM scripts are
useful as a numerical reference, but they do not establish a differentiable
256-state full-support implementation or a reverse adjoint.[^1]

Kaur, Guha, and Wilde use finite coherent-state constellations, entropic
continuity bounds, and finite Gauss--Hermite approximations to obtain an
asymptotic collective-attack security result. This supports the general
idea that approximation can be incorporated into a proof, but it is not the
same theorem as the project's source-moment interval and should not be used
to relabel an approximate \(C,w\) value as certified.[^2]

Ghorai and collaborators analyze discrete modulation with a semidefinite
programming approach for a small constellation. Lin, Upadhyaya, and
Lütkenhaus likewise provide a numerical asymptotic analysis for quaternary
modulation. These papers demonstrate useful alternative security
frameworks; neither supplies the required 256-state constrained reverse
derivative.[^3][^4]

Bäuml and collaborators prove a finite-size security result against
coherent attacks for a four-state heterodyne protocol using discretization,
entropy accumulation, semidefinite programming, and a photon-number cutoff.
This is important evidence that finite-size DM-CV-QKD security can be made
rigorous, but it is a different protocol and proof architecture from the
current 256-state source-moment path.[^5]

Composable security work for nonideal heterodyne detection further shows
that detector range and resolution must be represented explicitly when
making finite-size/composable claims.[^20] The present project should not
inherit those claims merely because its forward code computes a Holevo
quantity.

## 31. Large-QAM prior work

Large discrete constellations are not unprecedented. Experimental work has
reported high-order discrete-modulation systems using 64-QAM and 256-QAM
formats, and shaping work has studied 256-QAM distributions related to
Gauss--Hermite approximation.[^6][^7]

Those results establish engineering relevance, not the missing numerical
claim. In particular, they do not demonstrate:

- a full-support coherent-state Gram inverse at
  \(10^{-618}\)-scale eigenvalues;
- an exact C4 constrained reverse;
- a certified \(C,w\) interval error;
- a VJP validated against an independent high-precision oracle; or
- a sub-10-second full state at thousands of decimal digits.

The repository's challenge is therefore a specialized interaction between
large-QAM geometry, source-state linear dependence, and adaptive
differentiation. A paper should state that boundary explicitly rather than
implying that a large-QAM experiment validates it.

## 32. What the research must decide

The decision is not “exact or approximate” in the abstract. It is a choice
among routes with different security and engineering meanings:

1. keep the exact constrained graph and implement its reverse in compiled
   multiprecision;
2. keep exact forward certification but use a lower-precision exact graph
   only for optimization;
3. change the mathematical representation after proving exact
   equivalence and revalidating its VJP;
4. introduce a rigorous truncation theorem and a new security error term; or
5. use a surrogate/gradient-free optimizer with exact candidate screening.

The recommended primary route is route 1, with route 2 available only as a
clearly separated optimization mode if route 1 proves too slow. Route 3 is
worth testing as a kernel optimization, not as a change of security
functional. Route 4 is a new security-proof project. Routes 5 are fallback
engineering tools, not the main scientific result.

The current repository decision is consistent with this ranking:
skip an unstructured mpmath reverse and measure a compiled exact primitive
first.

## 34. Primary questions answered

### 34.1 Is a constrained reverse expected to be more stable?

**Answer:** More stable algebraically, not guaranteed more stable
numerically. It removes explicit inverse materialization and mirrors the
validated tangent equations. It does not remove the condition number of the
right solves or the square-root Fréchet operator. The expected gain is
fewer opportunities for formula and graph errors, not a theorem of bounded
gradient magnitude.

### 34.2 Can reverse mode avoid the huge inverse-spectrum intermediate?

**Answer:** It can avoid storing or forming an explicit inverse. It cannot
avoid inverse action. The adjoint right solve still contains \(G^H\) or
\(S^H\), and its solution can be huge. A small final \(dC\) or \(dw\) can
result from cancellation among large reverse intermediates.

### 34.3 What exact adjoint equations should be used?

**Answer:** For \(XG=Y\), solve
\(\bar YG^H=\bar X\) and update
\(\bar G\mathrel{+}=-X^H\bar Y\). Apply this to
\(B_sS_r=S_sD\) and \(A_sG_r=G_sD\) with the RHS product updates in
section 17. For \(S^2=G\), solve
\(S\bar G+\bar GS=\mathcal H(\bar S)\). Use real-pairing complex rules,
Hermitian projection, raw overlap derivatives, and C4 accumulation exactly
as written in sections 18--20.

### 34.4 What working precision is theoretically necessary?

**Answer:** There is no single global number from the current evidence. The
\(10^{-618}\) eigenvalue requires more than 618 reliable decimal digits to
resolve full support, and inverse/square-root derivatives can add hundreds
of digits of dynamic range. A practical first ladder is 1250, 1450, and
1650 decimal digits, with convergence required between levels. This is an
engineering ladder, not a proof that 1250 digits always suffice.

### 34.5 Could equilibration or scaling reduce precision requirements?

**Answer:** It can reduce element growth and improve a particular solve, but
it cannot remove a true small singular value. Exact scaling must be
propagated through the primal and adjoint equations. A successful benchmark
may reduce the required guard digits, but only a precision-ladder result can
establish that for the target family.

### 34.6 Is 800 decimal digits fundamentally necessary?

**Answer:** No universal conclusion follows. 800 digits is a locally
validated target setting because it resolves the observed support and
produces \(10^{-799}\)-scale residuals. A unitary basis or better
factorization may make fewer digits sufficient for some observables; a
nearby adaptive state may require more. The smallest support eigenvalue and
the full reverse condition must be remeasured.

### 34.7 Which compiled multiprecision backend is best?

**Answer:** Use C++17 with MPFR/MPC for the primary point-arithmetic
prototype: it provides a narrow, predictable foundation for custom
contiguous complex kernels and correct-rounded scalar arithmetic. Use
Arb/acb_mat in a secondary certification/reference mode. FLINT/Arb is
excellent when enclosure width is the priority, but its rigorous matrix
solve path may be slower or widen on this problem. Julia/Nemo is useful for
readability and cross-checks, not the first throughput claim.

### 34.8 What speedup is realistically possible?

**Answer:** Tens of times, and possibly low hundreds, are plausible from
compiled kernels, factor reuse, C4 sector parallelism, and reduced
allocation. The current evidence does not justify promising a thousandfold
gain. The exact result must come from a benchmark at the actual precision
ladder and hardware.

### 34.9 Can exact gradients plausibly reach below 10 seconds/state?

**Answer:** Not credibly as a current claim. Relative to the prior
1200--10800 second mpmath estimate, it requires 120--1080x. A narrowly
optimized C++ implementation may falsify this pessimism, so a primitive
benchmark is worthwhile, but sub-10-second full states remain an unproven
stretch target.

### 34.10 If not, what is the most defensible approximate-gradient workflow?

**Answer:** Differentiate the same solve-constrained graph at lower or mixed
precision, monitor residuals and support, use it only to propose
parameters, and re-evaluate every candidate with high-precision full
support. Never certify from the approximate gradient or from a learned
surrogate.

### 34.11 Can C,w errors be propagated conservatively into Z, chi, and SKR?

**Answer:** Yes for value errors, by interval arithmetic; no for gradient
errors alone. Let
\[
  C\in[C_-,C_+],\qquad w\in[w_-,w_+],\qquad 0\leq w_-\leq w_+.
\]
With \(a=2\sqrt T\) and \(b=\sqrt{2T\epsilon}\),

\[
  Z_- \in
  [aC_- - b\sqrt{w_+},\ aC_+ - b\sqrt{w_-}],
\]

\[
  Z_+ \in
  [aC_- + b\sqrt{w_-},\ aC_+ + b\sqrt{w_+}].
\]

Intersect the resulting outer interval with the project's physical
\([Z_{\rm phys}^-,Z_{\rm phys}^+]\). If the resulting outer interval is
\([Z_{\rm out}^-,Z_{\rm out}^+]\), a safe Holevo upper value is

\[
  \chi_{\rm safe}
  \geq\sup_{Z\in[Z_{\rm out}^-,Z_{\rm out}^+]}
              \chi_{BE}(Z),
\]

including the numerical error of the maximizer and entropy evaluation.
For a fixed candidate with an independently bounded mutual information,

\[
  K_{\rm safe}
  =\beta_{\rm rec}(I_{AB}^{\rm est}-\delta_I)
   -(\chi_{\rm est}+\delta_\chi)
\]

is conservative if the intervals and \(\delta_\chi\) are true outer
bounds. Evaluate the square roots by intervals directly; a derivative-based
bound is weak or singular near \(w=0\). An empirical AP discrepancy is not
a rigorous \(\delta_C\) or \(\delta_w\).

### 34.12 Can spectral truncation ever be security-rigorous?

**Answer:** Only with a new perturbation/security theorem that bounds the
state, inverse actions, entropy/Holevo term, and key-rate impact. A
thresholded pseudoinverse alone is not rigorous and is not the same
full-support functional.

### 34.13 What would reviewers likely accept?

**Answer:** Reviewers are most likely to accept a narrow, auditable claim:
the security theorem and equations are stated; the compiled reverse is
derived from exact right-solve and Sylvester adjoints; an independent AP or
Arb reference validates values and VJPs; residuals, precision convergence,
support, runtime, compiler, library versions, and hardware are published;
approximate training is separated from final certification; and no
finite-size, composable, or broader attack claim is made without its own
proof.

## 35. Final required recommendation

### Primary recommendation

Build one narrowly scoped C++17 compiled multiprecision prototype of the
exact C4 constrained graph using MPFR/MPC point arithmetic. Keep the
forward equations unchanged. Implement only:

1. a \(64\times64\) right solve and its adjoint right solve;
2. the principal square-root/Sylvester tangent and adjoint;
3. residual calculations in the real Frobenius pairing; and
4. one-sector factor reuse and timing.

Use 1250, 1450, and 1650 decimal digits. At each level require:

- primal and adjoint right-solve residuals;
- square-root and Sylvester residuals;
- Hermitian projection residuals;
- primal/adjoint inner-product mismatch;
- two-level agreement of scalar outputs and VJP components; and
- no nonfinite value, support loss, or unexplained pivot failure.

After the point kernels pass, add Arb/acb_mat reference runs for selected
fixtures and target points. The primary path remains exact full support;
Arb is a certification aid, not a reason to truncate modes.

The exact next repository task is the already authorized one-sector
benchmark, not a complete reverse. A proposed target is at most 10 seconds
for the one-sector primitive bundle at 1450 digits. This is a falsifiable
engineering gate, not current evidence.

### Failure criterion

Stop and keep adaptive training closed if any of the following occurs:

- residuals stop improving on the precision ladder;
- inner-product mismatch fails the declared tolerance;
- point and ball/reference results do not overlap;
- full-support positivity cannot be certified;
- the prototype exceeds the one-sector timing target by a material margin;
- the target VJP fails independent central-difference validation; or
- a proposed speedup depends on thresholding, jitter, pseudoinverse, or
  another change to the frozen functional.

If the exact route fails only the speed gate, use the same graph at lower
precision for optimization-only proposals and preserve high-precision
forward certification. If it fails an algebra or support gate, do not
substitute a surrogate and call the result exact.

## 36. Evidence standard

The next artifact should contain:

- exact source and security equations with theorem citations;
- source hashes and frozen-specification hash;
- compiler, flags, MPFR/MPC/Arb/FLINT versions, hardware, and thread count;
- decimal precision, guard digits, rounding mode, and retry policy;
- all solve and Sylvester residuals;
- support, Hermiticity, normalization, and pivot/inertia diagnostics;
- primitive adjoint inner-product tests;
- independent central-difference VJP tests for PS, GS-real,
  GS-imaginary, and \(V_A\);
- point-versus-ball overlap or an independent AP comparison;
- factor-reuse and wall-clock measurements;
- explicit distinction between measured, estimated, and proposed values;
- a full-\(Z\) value-error enclosure if security numbers are reported; and
- the exact lifecycle status and prohibited actions.

The existing four-direction tangent artifact is evidence for the forward
boundary only. The prior constrained reverse study is evidence for a
solve-based design and an mpmath practicality decision only. Neither is
evidence of a validated reverse VJP.

## 37. Core question in one sentence

The defensible path is an exact, solve-based C4 reverse implemented first as
a narrowly benchmarked compiled MPFR/MPC prototype, independently checked
with AP and Arb evidence, while every approximate gradient remains
optimization-only and every security claim uses a fresh full-support
forward enclosure.
