### 4.3 P2 — Stationary UAV Position Optimization

Define:

\[
S_{j,n}=(1-c_{j,n})K_j^\star.
\]

Then formulate:

\[
\boxed{
\mathrm{P2}:
\quad
\max_j
\frac1{N_t}
\sum_{n=1}^{N_t}S_{j,n}.
}
\]

Explain that P2 finds the best fixed UAV location under the complete cloud-blockage sequence.

This is an offline stationary benchmark.

### 4.4 P3 — Mobility-Aware Trajectory Optimization

Formulate:

\[
\boxed{
\mathrm{P3}:
\quad
\max_{\{j_n\}}
\left[
\frac1{N_t}
\sum_{n=1}^{N_t}S_{j_n,n}
-
\frac{\lambda}{D_{\rm ref}}
\sum_{n=2}^{N_t}d_{j_{n-1},j_n}
\right]
}
\]

subject to:

\[
d_{j_{n-1},j_n}
\leq v_{\max}\Delta t.
\]

Define:

- \(j_n\): selected UAV position at slot n.
- \(S_{j,n}\): usable SKR.
- \(d_{i,j}\): travel distance between positions.
- \(v_{\max}\): maximum UAV speed.
- \(\Delta t\): time-slot duration.
- \(\lambda\): mobility penalty.
- \(D_{\rm ref}\): reference distance.

Explain that the objective balances usable SKR and travel distance.

Use the same compact numbered optimization-problem format as the GLOBECOM reference.

Avoid excessively long equations that overflow IEEE columns.

Do not change the normalization or movement constraints.

# PART D — PRESENT THE PROPOSED ALGORITHMS

## 5. Greedy and Dynamic Programming

Write a concise proposed-solution subsection using the GLOBECOM optimization-algorithm presentation style.

### Greedy Baseline

At the initial slot:

\[
j_1^{\mathrm G}
\in
\arg\max_jS_{j,1}.
\]

For later slots:

\[
j_n^{\mathrm G}
\in
\arg\max_{j\in\mathcal N(j_{n-1})}
\left[
S_{j,n}
-
\frac{N_t\lambda}{D_{\rm ref}}
d_{j_{n-1},j}
\right].
\]

Explain that Greedy chooses the best immediate reward among feasible next positions.

It does not account for future cloud states when selecting the current action.

### Dynamic Programming

Define:

\[
F_1(j)=S_{j,1}.
\]

Use the Bellman recursion:

\[
F_n(j)=S_{j,n}
+
\max_{i\in\mathcal N(j)}
\left[
F_{n-1}(i)
-
\frac{N_t\lambda}{D_{\rm ref}}d_{i,j}
\right].
\]

The optimal trajectory is recovered through backtracking.

State the complexity:

\[
O(N_tJ^2)
\]

in the dense-transition worst case.

Explain that DP optimizes the finite-horizon penalized objective under the given spatial grid and complete cloud-state information.

### Algorithm Layout

The GLOBECOM paper presents a compact algorithm box.

Consider using a short IEEE-compatible algorithm environment titled:

**Algorithm 1: Dynamic Programming for Mobility-Aware UAV Positioning**

Include only essential steps:

1. Input candidate locations, usable-SKR matrix, lambda and speed constraints.
2. Initialize the first slot.
3. Evaluate feasible predecessor transitions.
4. Store the best score and predecessor.
5. Select the best terminal state.
6. Backtrack to recover the optimal trajectory.

Avoid an excessively long pseudocode block.

If a full algorithm box makes the Optimization-to-Conclusion portion exceed the allowed page budget, prioritize the Bellman recursion and a short algorithmic paragraph.

Do not sacrifice essential equations to accommodate decorative pseudocode.
