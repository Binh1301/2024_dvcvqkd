# PHASE 2 — Mathematical Consistency Audit

## 3. Audit the SKR Calculation

The current implementation calculates:

\[
K=\beta I_{AB}-\chi_{BE}.
\]

The effective fading-channel parameters are:

\[
\eta_f=\langle\sqrt{\eta}\rangle^2
\]

and

\[
\eta_f\xi_f
=
(\langle\eta\rangle-\eta_f)V_A
+\xi_{\rm ch}\langle\eta\rangle.
\]

The corrected channel excess-noise convention is:

\[
\xi_n=\xi_{\rm ch}.
\]

The current numerical evaluator uses:

- Two-dimensional mutual information for 256-QAM.
- The homodyne conditional symplectic eigenvalue for Holevo information.
- Trusted-detector assumptions.
- Exact source moments \(C,w\).
- The source normalization \(V_A=2\langle n\rangle\).

These conventions must be audited carefully.

### Audit A — Mutual Information

The existing manuscript-style calculation uses:

\[
I_{AB}^{2D}
=
\sum_kp_k
\int_{\mathbb C}
p(y|\alpha_k)
\log_2
\frac{p(y|\alpha_k)}
{\sum_jp_jp(y|\alpha_j)}
\,d^2y.
\]

Determine whether this corresponds to a physically realizable measurement model under the stated homodyne protocol.

Examine:

- Measurement outcome dimensionality.
- Gaussian normalization.
- Shot-noise convention.
- Signal normalization.
- Whether Bob measures one or both quadratures.
- How the selected measurement affects \(I_{AB}\).

Clearly distinguish the existing manuscript-style implementation from a physically consistent homodyne implementation.

### Audit B — Holevo Information

The current evaluator uses:

\[
\nu_3=
\sqrt{
V\left(V-\frac{Z^2}{W}\right)
}.
\]

Verify the measurement assumptions under which this expression is valid.

Determine whether combining this expression with the existing 2D mutual information is mathematically and physically justified.

Do not automatically replace any formula.

If the model is inconsistent, identify the exact equations that conflict and provide a proposed correction separately.

### Audit C — Trusted Detector

Verify whether the manuscript consistently models:

- Detector efficiency.
- Trusted electronic noise.
- Channel excess noise.
- Loss-induced vacuum noise.
- Input-referred versus output-referred noise.

Do not add trusted detector imperfections to the channel excess-noise parameter without a consistent security model.

### Audit D — Source Normalization

Check the relationship between:

\[
V_A,\quad \langle n\rangle,\quad
\alpha_k,\quad p_k.
\]

The verified source cache uses:

\[
V_A=2\langle n\rangle.
\]

Identify any conflicting convention in the manuscript.

Verify that the source moments \(C,w\) and numerical SKR calculations use the same normalization.

### Audit E — Fading Security Approximation

Determine:

- Whether the effective covariance treatment supports the stated SKR bound.
