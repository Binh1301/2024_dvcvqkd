# PHASE 1 — P1: SOURCE OPTIMIZATION

## 4. Optimize Source Parameters at Each UAV Position

The clear-sky SKR at position \(j\) is

\[
K_j(\nu,V_A)
=
\beta_{\rm rec}I_{AB,j}(\nu,V_A)
-
\chi_{BE,j}(\nu,V_A).
\]

The source optimization is

\[
\boxed{
(\nu_j^\star,V_{A,j}^\star)
\in
\arg\max_{(\nu,V_A)\in\mathcal G}
K_j(\nu,V_A).
}
\]

The usable clear-sky SKR is

\[
\boxed{
K_j^\star=
\left[
\max_{(\nu,V_A)\in\mathcal G}
K_j(\nu,V_A)
\right]^+.
}
\]

Here,

\[
[x]^+=\max(x,0).
\]

### Requirements

For every UAV position:

1. Determine its three-dimensional geometry relative to the HAP.
2. Calculate the corresponding link distance and zenith angle.
3. Recalculate the physical optical channel.
4. Calculate \(\langle\eta\rangle\), \(\langle\sqrt\eta\rangle\), \(\eta_f\), and \(\xi_f\).
5. Evaluate SKR for every relevant exact-source candidate.
6. Find the optimal source parameters.
7. Save the maximum raw SKR and the usable nonnegative SKR separately.

Perform this optimization independently for all \(J=100\) candidate positions.

### Source catalog

Use the verified source catalog already present in the repository.

Identify the available Uniform and MB candidates and check their exact-source provenance.

Reuse matching \(C,w\) moments.

Do not interpolate source moments.

Do not regenerate the entire exact-source catalog if the necessary candidates are already available.

For each candidate, ensure consistency between:

- Constellation geometry.
- Source probabilities.
- Modulation variance.
- Exact \(C,w\) values.
- Source normalization conventions.

### Important optimization rule

Maximize raw SKR first.

Apply

\[
[x]^+
\]

only after selecting the largest raw SKR.

Do not clip individual negative candidates before recording the optimization results.

### Expected P1 outputs

# PHASE 4 — P3: MOBILITY-AWARE TRAJECTORY OPTIMIZATION

## 7. Dynamic UAV Trajectory Optimization

Let the UAV trajectory be:

\[
\mathbf j=(j_1,\ldots,j_{N_t}).
\]

Define the horizontal travel distance between candidate positions:

\[
d_{i,j}
=
\|\mathbf q_i-\mathbf q_j\|_2.
\]

The UAV must satisfy:

\[
\boxed{
d_{j_{n-1},j_n}
\leq v_{\max}\Delta t.
}
\]

The P3 optimization objective is:

\[
\boxed{
\begin{aligned}
\max_{j_1,\ldots,j_{N_t}}\quad
&\frac1{N_t}
\sum_{n=1}^{N_t}S_{j_n,n}\\
&-\frac{\lambda}{D_{\rm ref}}
\sum_{n=2}^{N_t}d_{j_{n-1},j_n}.
\end{aligned}
}
\]

Do not remove or redefine the mobility penalty.

Keep units consistent:

- \(S_{j,n}\): bits/use.
- \(d_{i,j}\) and \(D_{\rm ref}\): same distance unit.
- \(\lambda\): bits/use.

The initial UAV position is freely selectable, as assumed in the manuscript.

No initial deployment cost is included.

The optimization is an offline problem with the cloud-state matrix known over the mission horizon.

## 8. Dynamic Programming Algorithm

Use the exact DP formulation in the manuscript.

Define feasible predecessors:

\[
\boxed{
\mathcal N(j)
=
\{i:d_{i,j}\leq v_{\max}\Delta t\}.
}
\]

Use the cumulative reward convention:

\[
F_1(j)=S_{j,1}.
\]

For \(n\geq2\):

\[
\boxed{
F_n(j)
=
S_{j,n}
+
\max_{i\in\mathcal N(j)}
\left[
F_{n-1}(i)
-
\frac{N_t\lambda}{D_{\rm ref}}d_{i,j}
\right].
}
\]

Store the maximizing predecessor:

\[
B_n(j)
=
\arg\max_{i\in\mathcal N(j)}
\left[
F_{n-1}(i)
-
\frac{N_t\lambda}{D_{\rm ref}}d_{i,j}
\right].
\]

Recover the optimal path through backtracking.

The optimal objective value is

\[
\boxed{
U^\star=
\frac1{N_t}\max_jF_{N_t}(j).
}
\]

### Mandatory validation

Check that the scaling factor \(N_t\) in the movement penalty is consistent with the original P3 objective.

Verify:

1. Every transition satisfies the speed constraint.
2. The DP trajectory remains within the candidate grid.
3. The backtracked path matches the optimal DP score.
4. The cumulative travel distance is calculated correctly.
5. The direct evaluation of P3 matches the DP objective.
6. Zero movement is always feasible.
7. The DP solution is no worse than the best stationary trajectory in terms of the same P3 objective.

For small synthetic test cases, compare the DP solution against exhaustive enumeration.

Confirm optimality only on the finite grid under the specified cloud realization.

# PHASE 5 — GREEDY BASELINE

## 9. Implement Greedy UAV Positioning

Follow Section II-B and Algorithm 1 of the manuscript.

Initialize:

\[
j_1^{G}
\in
\arg\max_j S_{j,1}.
\]

For each subsequent slot:

\[
\boxed{
j_n^G
\in
\arg\max_{j:
d_{j_{n-1}^G,j}\leq v_{\max}\Delta t}
\left[
S_{j,n}
-
\frac{N_t\lambda}{D_{\rm ref}}
d_{j_{n-1}^G,j}
\right].
}
\]

The Greedy algorithm uses only the cloud state of the current slot.

It does not look ahead to future clouds.

Use deterministic tie-breaking and document the rule.

The Greedy and DP methods must have:

- Identical channel statistics.
- Identical source optimization results.
- Identical cloud-state matrix.
- Identical UAV speed constraints.
- Identical mobility penalty.
- Identical initial-position assumptions.

Do not allow Greedy to access future cloud states.
