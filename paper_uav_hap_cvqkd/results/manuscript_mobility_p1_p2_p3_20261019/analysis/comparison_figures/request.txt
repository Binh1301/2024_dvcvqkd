## 3. Mathematical Definitions

For a UAV trajectory

\[
\mathbf j=(j_1,\ldots,j_{N_t}),
\]

the average usable secret-key rate is

\[
\boxed{
\overline K
=
\frac{1}{N_t}
\sum_{n=1}^{N_t}S_{j_n,n}.
}
\]

The total UAV travel distance is

\[
\boxed{
D=
\sum_{n=2}^{N_t}
\|\mathbf q_{j_n}-\mathbf q_{j_{n-1}}\|_2.
}
\]

The mobility-penalized objective is

\[
\boxed{
U=
\overline K-\frac{\lambda D}{D_{\rm ref}}.
}
\]

The three methods must be compared using the same:

- Cloud realization.
- UAV position grid.
- Mission duration.
- Physical channel model.
- Source catalog.
- Mobility penalty.
- Flight constraints.

Use raw unrounded numerical data when calculating statistics.

Do not calculate statistics using rounded values copied from reports.
