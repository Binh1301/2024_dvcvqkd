\left[
\max_{(\nu,V_A)\in\mathcal G}

## 5. Analyze P3 — Dynamic Programming Versus Greedy and Stationary

The mobility-aware objective is

\[
U(\mathbf j)
=
\frac{1}{N_t}
\sum_{n=1}^{N_t}S_{j_n,n}
-
\frac{\lambda}{D_{\rm ref}}
\sum_{n=2}^{N_t}
d_{j_{n-1},j_n}.
\]

For each method, calculate:

\[
\overline K
=
\frac1{N_t}
\sum_{n=1}^{N_t}S_{j_n,n},
\]

\[
D
=
\sum_{n=2}^{N_t}
d_{j_{n-1},j_n},
\]

\[
U
=
\overline K-\frac{\lambda D}{D_{\rm ref}}.
\]

Compare:

- Optimal Stationary.
- Greedy.
- Dynamic Programming.

Across all 100 missions and 10 values of \(\lambda\), report:

1. Mean and standard deviation of \(\overline K\).

3. Mean and standard deviation of \(U\).
4. Median and 5th/95th percentiles.
5. DP minus Stationary improvement.
6. DP minus Greedy improvement.
7. Number and proportion of missions where DP strictly outperforms each baseline.
8. Number of UAV position changes per trajectory.
9. Fraction of slots with a usable QKD link.

Compare all methods using the same cloud mission and the same mobility-penalty value.

Report both absolute and relative improvements, but calculate percentages only when the reference denominator is strictly positive and numerically meaningful.
