## 6. Compare Three Positioning Algorithms

Use the identical mobility constraints and objective for all algorithms.

The optimization objective is:

\[
\boxed{
U=
\frac{1}{N_t}\sum_{n=1}^{N_t}S_{j_n,n}
-
\frac{\lambda}{D_{\rm ref}}
\sum_{n=2}^{N_t}d_{j_{n-1},j_n}.
}
\]

Subject to:

\[
d_{j_{n-1},j_n}\leq v_{\max}\Delta t.
\]

Use:

\[
d_{ij}=\|\mathbf q_i-\mathbf q_j\|_2.
\]

The initial UAV location is freely selected, unless the canonical baseline explicitly requires otherwise.

The UAV may remain in the same position.

No terminal-return penalty is applied unless already part of the approved baseline.

### Algorithm A — Stationary

Choose a single fixed UAV position maximizing average usable SKR over the mission:

\[
j_{\rm fix}^\star
=
\arg\max_j
\frac{1}{N_t}
\sum_{n=1}^{N_t}S_{j,n}.
\]

The UAV remains at that position for all slots.

Travel distance is zero.

This is an offline optimal stationary benchmark because the entire cloud sequence is used for choosing the fixed location.

### Algorithm B — Greedy

At the first time slot:

\[
j_1^G=\arg\max_j S_{j,1}.
\]

For every subsequent slot:

\[
j_n^G=
\arg\max_{j\in\mathcal N(j_{n-1}^G)}
\left[
\frac{S_{j,n}}{N_t}
-\frac{\lambda}{D_{\rm ref}}
d_{j_{n-1}^G,j}
\right].
\]

Greedy uses current-slot cloud information only when choosing its next location.

It must not use future cloud states.

Use deterministic tie-breaking.

### Algorithm C — Dynamic Programming

Use finite-horizon DP with the full cloud sequence available offline.

Initialization:

\[
F_1(j)=\frac{S_{j,1}}{N_t}.
\]

Recursion:

\[
\boxed{
F_n(j)=
\frac{S_{j,n}}{N_t}
+
\max_{i\in\mathcal N(j)}
\left[
F_{n-1}(i)
-
\frac{\lambda}{D_{\rm ref}}d_{ij}
\right].
}
\]

Store backpointers and reconstruct the optimal grid trajectory.

Confirm DP solves the same penalized objective used to evaluate Greedy and Stationary.

The DP outcome must satisfy:

\[
U_{\rm DP}\geq U_{\rm Greedy},
\]

\[
U_{\rm DP}\geq U_{\rm Stationary}
\]

for each identical simulation instance, within numerical tolerance, provided all three policies use the same feasible initial-position and movement conventions.

If these inequalities fail, investigate a potential implementation or objective-scaling error.

DP's superiority in this penalized objective does not imply it must individually achieve the largest unpenalized mean rate, smallest distance, or highest availability.
