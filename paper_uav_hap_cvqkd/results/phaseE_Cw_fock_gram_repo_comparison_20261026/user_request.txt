## 2. Canonical Mathematical Definitions

For an ensemble of M coherent states:

\[
\mathcal E=\{p_k,\alpha_k\}_{k=1}^{M},
\]

construct the density operator:

\[
\tau=\sum_{k=1}^{M}p_k
|\alpha_k\rangle\langle\alpha_k|.
\]

Define:

\[
a_\tau=\tau^{1/2}a\tau^{-1/2},
\]

where tau^(-1/2) is the Moore–Penrose inverse square root on the support of tau.

The canonical source moments are:

\[
\boxed{
C=\operatorname{Tr}
(\tau^{1/2}a\tau^{1/2}a^\dagger)
}
\]

and:

\[
\boxed{
w=\sum_k p_k
\left[
\langle\alpha_k|a_\tau^\dagger a_\tau|\alpha_k\rangle
-
|\langle\alpha_k|a_\tau|\alpha_k\rangle|^2
\right].
}
\]

These definitions must be identical for all three implementations.

The approved v43 correlation formula remains:

\[
Z(\eta_f,\xi_f)
=
2\sqrt{\eta_f}C-
\sqrt{2\eta_f\xi_f w}.
\]

Do not change Eq. (14), optimize Z, choose alternative correlation endpoints, or introduce clipping.

The source calculations must remain independent of eta_f, xi_f and zenith angle.

## 4. Task B — Method A: Direct Fock-Space Calculation

Implement an independent numerical reference using the truncated Fock basis.

For each coherent state:

\[
|\alpha_k\rangle
=
e^{-|\alpha_k|^2/2}
\sum_{n=0}^{N_F-1}
\frac{\alpha_k^n}{\sqrt{n!}}|n\rangle.
\]

Construct:

\[
\tau_F=\sum_k p_k
|\alpha_k\rangle_F\langle\alpha_k|_F.
\]

Define the annihilation matrix:

\[
a_{n-1,n}=\sqrt n.
\]

Compute the Hermitian eigendecomposition:

\[
\tau_F=U\Lambda U^\dagger.
\]

Use it to construct:

\[
\tau_F^{1/2}
=
U\Lambda^{1/2}U^\dagger,
\]

\[
\tau_F^{-1/2}
=
U\Lambda_{\rm MP}^{-1/2}U^\dagger.
\]

Then calculate:

\[
C_A=
\operatorname{Tr}
(\tau_F^{1/2}a\tau_F^{1/2}a^\dagger).
\]

Construct:

\[
a_{\tau,F}
=
\tau_F^{1/2}a\tau_F^{-1/2}.
\]

Calculate w both ways:

1. The direct weighted variance formula.
2. A numerically stable orthogonal-residual formula.

For normalized coherent-state vectors v_k:

\[
w_A=
\sum_k p_k
\left\|
(I-v_kv_k^\dagger)
a_{\tau,F}v_k
\right\|^2.
\]

The latter avoids subtracting two nearly equal positive numbers.

Explicitly check that the residual formula and direct variance expression are algebraically equivalent under the normalization assumptions.

- Runtime

## 5. Task C — Method B: Coherent-State Gram Matrix

Build an independent implementation using the coherent-state overlap identity:

\[
\langle\alpha_i|\alpha_j\rangle
=
\exp\left[
-\frac{|\alpha_i|^2+|\alpha_j|^2}{2}
+\alpha_i^*\alpha_j
\right].
\]

Construct the weighted Gram matrix:

\[
H_{ij}
=
\sqrt{p_ip_j}
\langle\alpha_i|\alpha_j\rangle.
\]

Also construct the weighted annihilation matrix elements using:

\[
\langle\alpha_i|a|\alpha_j\rangle
=
\alpha_j\langle\alpha_i|\alpha_j\rangle.
\]

Use a Hermitian spectral decomposition of H to obtain the nonzero spectrum of tau and an orthonormal basis for its support.

Compute the source moment C from:

\[
\boxed{
C_B=
\sum_{r,s}
\sqrt{\lambda_r\lambda_s}
\left|
\langle\phi_r|a|\phi_s\rangle
\right|^2.
}
\]

Here lambda_r and phi_r are the eigenvalues and orthonormal eigenstates of tau.

Construct a_tau on the support using the exact Moore–Penrose convention.

Calculate w using the weighted variance of a_tau in the coherent states.

Implement a stable residual-norm version as an independent check.

Avoid rebuilding a large Fock-space density matrix in Method B.

If the Gram matrix is severely ill-conditioned, report its condition number, eigenvalue spectrum and precision limitations.

Do not discard eigenvalues solely because doing so brings the result closer to the repository.

Any rank truncation or precision change must be explicitly justified.
