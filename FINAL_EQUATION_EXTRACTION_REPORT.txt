[CRITICAL] EQ. 3: NOISE DEFINITIONS
STATUS: ✅ FOUND (Page ~6-8)

This is THE fundamental equation. All key rates depend on these noise terms.

A. CHANNEL EXCESS NOISE (ε_ch)
   ε_ch [SNU] ≈ 0.0186
   Breakdown: 0.0060 (turbulence) + 0.0100 (pointing jitter) + 0.0018 (frequency 
              drift) + 0.0005 (phase noise) + 0.0002 (polarization) + 0.0001 (thermal)

B. DETECTOR EXCESS NOISE (ε_det)
   ε_det [SNU] ≈ 0.0135
   Breakdown: 0.0130 (InGaAs shot noise) + 0.0002 (dark current) + 0.0001 (thermal)
              + 0.0001 (timing jitter) + 0.0001 (other)

C. CHANNEL LOSS NOISE (χ_line) - EQUATION 3, TERM 1
   χ_line(T, ε_ch) = 1/T - 1 + ε_ch  [SNU]
   
   Physical meaning: 
     (1/T - 1) = thermal noise from modes lost to channel
     + ε_ch = excess technical noise
   
   Range examples:
     T=0.01 (high loss): χ_line ≈ 99 + 0.0186 ≈ 99.02
     T=0.1 (moderate): χ_line ≈ 9 + 0.0186 ≈ 9.02
     T=0.9 (low loss): χ_line ≈ 0.111 + 0.0186 ≈ 0.13

D. HOMODYNE DETECTOR NOISE (χ_hom) - EQUATION 3, TERM 2
   χ_hom = (1 - η + ε_det) / η  [SNU]
   where η = 0.6 (InGaAs detector efficiency at 1550 nm)
   
   Numerator breakdown:
     (1 - η) = 0.4 : inefficiency of 60% efficient detector
     ε_det = 0.0135 : detector shot noise, dark current, thermal
   
   χ_hom = (1 - 0.6 + 0.0135) / 0.6 ≈ 0.6892 [SNU]  (CONSTANT, detector property)

E. HETERODYNE DETECTOR NOISE (χ_het) - EQUATION 3, TERM 2B (alternative)
   χ_het = (1 + (1-η) + 2·ε_det) / η  [SNU]
   
   Factor of 2 on ε_det because heterodyne measures 2 quadratures:
     (1 - η) = 0.4 : inefficiency
     2·ε_det = 0.0270 : both X and P quadratures add independent noise
   
   χ_het = (1 + 0.4 + 0.0270) / 0.6 ≈ 1.3783 [SNU]  (≈ 2× homodyne, CONSTANT)
   
   Note: Heterodyne is used for M-QAM (Eq. 16-20)

F. TOTAL HOMODYNE RECEIVER NOISE (χ_tot^hom) - EQUATION 3, PRIMARY
   χ_tot^hom = χ_line + χ_hom/T  [SNU]
               = (1/T - 1 + ε_ch) + χ_hom/T
   
   Interpretation:
     χ_line: channel loss + excess noise (grows with loss)
     χ_hom/T: detector noise scaled by loss (diverges as T→0)
   
   CRITICAL: The 1/T scaling means high loss AMPLIFIES detector noise!
   At T=0.01 (1% transmittance):
     χ_tot^hom ≈ 99 + (0.6892/0.01) ≈ 99 + 69 ≈ 168 [SNU]

G. TOTAL HETERODYNE RECEIVER NOISE (χ_tot^het) - EQUATION 3, ALTERNATIVE
   χ_tot^het = χ_line + χ_het/T  [SNU]
               = (1/T - 1 + ε_ch) + χ_het/T
   
   Same structure, different detector noise constant (χ_het vs χ_hom)

    B = [T(V_A+1)² + T(V_A+1)χ_line - T·Z²]²
    λ₁,₂ = √{ 0.5·[A ± √(A² - 4B)] }

    D = [√B·(V_A+1+√B·χ_hom)] / [T(V_A+1+χ_tot)]

DISCRETE MODULATION M-QAM (Eq. 13-20) - Section II-C, Heterodyne
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EQ. 13: M-QAM Modulation Alphabet
STATUS: ✅ FOUND (Page ~10)
MATHEMATICAL FORM:
  M-QAM Grid: m×m constellation on 2D rectangular lattice (m = √M)
  Each point: α_k,l = a_k + i·a_l
  
  Amplitude on each axis:
    a_j = scale · (j - (m-1)/2),  j ∈ {0,...,m-1}
    scale = √(V_A/2) / √(m-1)  [normalized for equal variance per quadrature]
  
  Probability distribution:
    p_k,l = p(k)·p(l)  where p(j) = binomial(m-1, j) / 2^(m-1)
  
  Coherent state coupling introduces Z* bound (lower bound on Eve's information):
  Z*² = [2√T · Tr(ρ_ensemble)]² - ε_ch·w·noise_variance

PYTHON IMPLEMENTATION:
  def _Zstar_qam(T, eps, VA, M):
      m = int(round(np.sqrt(M)))
      ks = np.arange(m)
      pk = np.array([float(sp_comb(m-1, k, exact=True)) for k in ks])
      pk /= pk.sum()  # normalize
      
      scale = np.sqrt(VA/2)/np.sqrt(m-1) if m > 1 else 0.0
      alpha = np.array([scale*((k-(m-1)/2) + 1j*(l-(m-1)/2))
                        for k in ks for l in ks])
      prob = np.array([pk[k]*pk[l] for k in range(m) for l in range(m)])
      
      tr = float(np.sum(prob*np.abs(alpha)**2))
      w = float(np.sum(prob*(np.abs(alpha)**2 - tr)**2))
      
      Zs = 2*np.sqrt(T)*tr - np.sqrt(2*T*eps)*np.sqrt(max(w,0))
      return max(float(Zs), 0.0)

VARIABLES:
  M : Constellation size (4, 16, 64, 256, ...)
  m = √M : Grid dimension
  p_k : Binomial distribution on axis [dimensionless]
  α_k,l : Complex amplitude on 2D grid [SNU^(1/2)]
  V_A : Total modulation variance (~1/2 per quadrature) [SNU]
  Z* : Effective amplitude bound [SNU^(1/2)]

EQ. 16: Asymptotic SKR - M-QAM Heterodyne
STATUS: ✅ FOUND (Page ~11)
MATHEMATICAL FORM:
  K_∞^QAM [bits/pulse] = β · log₂((V_A + 1 + χ_tot) / (1 + χ_tot)) × 1.0
                         - χ_BE^QAM(M, Z*)
  
  where:
    χ_BE^QAM = heterodyne Holevo bound (Eq. 17-19)
    Note: NO 0.5 factor (heterodyne measures both quadratures)
    Z* = effective amplitude bound from Eq. 13 (binomial distribution)

PYTHON IMPLEMENTATION:
  def skr_qam(VA, T, eps, M, beta):
      if T <= 1e-6:
          return 0.0
      return beta*_IAB_het(VA, _chi_t_het(T,eps)) - _holevo_qam_het(VA,T,eps,M)

COMPARISON WITH GM (Eq. 4):

  QAM (Eq.16): K_∞^QAM = β·1.0·log₂(...) - χ_BE^QAM  [heterodyne, 2 quadratures]
  
  Factor of 2 in mutual information between protocols, but different Holevo bounds.

  T : Channel transmittance (linear)
  ε_ch : Channel excess noise [SNU]

  β : Reconciliation efficiency

EQ. 17-19: Holevo Bound - M-QAM Heterodyne (Symplectic Eigenvalues)
STATUS: ✅ FOUND (Page ~11-12)
MATHEMATICAL FORM:
  χ_BE^het [bits/pulse] = G((λ₁-1)/2) + G((λ₂-1)/2) - G((λ₃-1)/2)
  
  Symplectic eigenvalues for 2-mode heterodyne:
    a₁₁ = V_A + 1
    a₂₂ = 1 + T·V_A + T·ε_ch
    θ = (a₁₁ + a₂₂) / 2
    Δ = a₁₁·a₂₂ - Z*²
    disc = θ² - Δ
    
    λ₁ = √(θ + √disc)
    λ₂ = √max(θ - √disc, 10^(-30))
    λ₃ = √max(V_A + 1 - Z*² / (2 + T·V_A + T·ε_ch), 10^(-15))

PYTHON IMPLEMENTATION:
  def _holevo_qam_het(VA, T, eps, M):
      Zs = _Zstar_qam(T, eps, VA, M)
      a11 = VA+1
      a22 = 1+T*VA+T*eps
      th = (a11+a22)/2
      dt = a11*a22 - Zs**2
      dsc = max(th**2-dt, 0)
      
      l1 = np.sqrt(th+np.sqrt(dsc))
      l2 = np.sqrt(max(th-np.sqrt(dsc), 1e-30))
      l3 = max(VA+1 - Zs**2/(2+T*VA+T*eps), 1e-15)
      
      return _G((l1-1)/2)+_G((l2-1)/2)-_G((l3-1)/2)

VARIABLES:
  λ₁, λ₂, λ₃ : Symplectic eigenvalues (only 3 independent for heterodyne 2-mode)
  Z* : Effective amplitude from M-QAM (Eq. 13/20)
  χ_BE^het : Holevo bound for heterodyne M-QAM [bits/pulse]

───────────────────────────────────────────────────────────────────────────────

EQ. 20: Z* Lower Bound (Binomial Distribution)
STATUS: ✅ FOUND (Page ~12)

Referenced and implemented in Eq. 13 (_Zstar_qam function).

PHYSICAL MEANING:
  Eq. 20 provides the lower bound on effective signal amplitude after channel 
  loss and excess noise corruption for M-QAM constellations.
  
  Uses binomial probability distribution to weight different amplitudes in the 
  m×m grid, accounting for:
    - Uniform distribution of symbols
    - Channel loss scaling (√T factor)
    - Excess noise corruption (ε_ch term)
  
  Used in heterodyne detection (Eq. 17-19) for M-QAM key rate calculation.

FORMULA (implicit in Eq. 13):
  Z* = 2√T · E[|α|²] - √(2T·ε_ch) · √(Var[|α|²])
  
  where expectation and variance taken over binomial distribution of QAM grid.

PYTHON IMPLEMENTATION: See _Zstar_qam() above

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
QUANTUM/CHANNEL VARIABLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

V_A (Modulation Variance)
  Definition: Variance of Alice's quantum state (squeezed/modulated state)
  Units: SNU (Shot-Noise Units)
  Typical Values:
    - Gaussian Modulation (GM): 5.0 SNU
    - M-PSK Discrete: 0.5 SNU
    - M-QAM Discrete: 2.0 SNU
  Physical Range: 0.01 - 10 SNU
  Impact on SKR: Higher V_A → stronger signal → higher key rate (until noise dominates)

T (Channel Transmittance)
  Definition: Effective transmission probability for signal power through channel
  Units: Linear [0, 1] (dimensionless)
  Typical Satellite Values: 0.001 - 0.1 (0.1% - 10%)
  Formula: T = 10^(-(A_geo + A_scat + A_sci)/10) where A_i in dB
  Physical Range: 10^-6 to 1.0
  Impact on SKR: T determines noise amplification; higher loss → lower key rate exponentially

ε_ch (Channel Excess Noise)
  Definition: Total excess noise from atmospheric turbulence, pointing jitter, frequency drift, phase noise
  Units: SNU (Shot-Noise Units)
  Typical Value: 0.0186 SNU
  Breakdown:
    0.0060 : Atmospheric turbulence
    0.0100 : Pointing jitter
    0.0018 : Frequency drift
    0.0005 : Phase noise
    0.0002 : Polarization walk
    0.0001 : Thermal noise
  Physical Range: 0.001 - 0.1 SNU
  Impact on SKR: Adds directly to χ_line and χ_tot; higher ε_ch → lower key rate

ε_det (Detector Excess Noise)
  Definition: Total excess noise from detector (shot noise, dark current, thermal, etc.)
  Units: SNU (Shot-Noise Units)
  Typical Value: 0.0135 SNU
  Breakdown (InGaAs detector):
    0.0130 : Shot noise
    0.0002 : Dark current
    0.0001 : Thermal noise
    0.0001 : Timing jitter
    0.0001 : Other
  Physical Range: 0.001 - 0.02 SNU
  Impact on SKR: Determines χ_hom and χ_het; higher ε_det → higher detector noise → lower key rate

χ_line (Channel Loss Noise)
  Definition: Thermal noise from quantum vacuum fluctuations in lost modes
  Formula: χ_line = 1/T - 1 + ε_ch
  Units: SNU
  Physical Interpretation: (thermal from loss) + (excess technical noise)
  Examples:
    T=0.01  → χ_line ≈ 99
    T=0.1   → χ_line ≈ 9
    T=0.9   → χ_line ≈ 0.11
  Impact on SKR: Dominates at high loss (low T); appears in χ_tot and Holevo bound

χ_hom (Homodyne Detector Noise - CONSTANT)
  Formula: χ_hom = (1 - η + ε_det) / η
           where η = 0.6 (detector efficiency), ε_det = 0.0135
  Units: SNU
  Numerical Value: χ_hom ≈ 0.6892 [SNU]
  Physical Interpretation: Noise from single-quadrature homodyne detection
  Detector Parameters:
    η = 0.6 : InGaAs detector efficiency at λ=1550 nm
    ε_det = 0.0135 : Detector excess noise
  Impact on SKR: Constant contribution; appears in χ_tot^hom = χ_line + χ_hom/T
  Note: This is a DETECTOR PROPERTY, not dependent on signal

χ_het (Heterodyne Detector Noise - CONSTANT)
  Formula: χ_het = (1 + (1-η) + 2·ε_det) / η
           where factor of 2 on ε_det (X and P quadratures both measured)
  Units: SNU
  Numerical Value: χ_het ≈ 1.3783 [SNU]
  Physical Interpretation: Noise from dual-quadrature heterodyne detection
  Relationship: χ_het ≈ 2 × χ_hom (roughly, due to 2 quadratures)
  Impact on SKR: Appears in χ_tot^het for M-QAM protocol
  Note: Only χ_hom used in GM and M-PSK (homodyne); χ_het used in M-QAM (heterodyne)

χ_tot^hom (Total Homodyne Receiver Noise)
  Formula: χ_tot^hom = χ_line + χ_hom/T = (1/T - 1 + ε_ch) + χ_hom/T
  Units: SNU
  Physical Meaning: Quantum noise at Bob's receiver after channel loss
  Expansion: χ_tot^hom = (1/T - 1) + ε_ch + χ_hom/T
    (1/T - 1) : vacuum noise from lost signal modes
    ε_ch : excess channel noise
    χ_hom/T : detector noise amplified by channel loss
  Critical Behavior:
    T→0 (high loss): χ_tot^hom → ∞ (due to 1/T divergence)
    T→1 (low loss): χ_tot^hom → ε_ch + χ_hom ≈ 0.046 (shot noise limited)
  Impact on SKR: CRITICAL - appears in every key rate formula
    Higher χ_tot → lower mutual information I_AB → lower key rate

χ_tot^het (Total Heterodyne Receiver Noise)
  Formula: χ_tot^het = χ_line + χ_het/T = (1/T - 1 + ε_ch) + χ_het/T
  Units: SNU
  Same structure as χ_tot^hom but with χ_het instead of χ_hom
  Numerical: χ_tot^het ≈ χ_tot^hom + (χ_het - χ_hom)/T ≈ χ_tot^hom + 0.69/T

Z_Gaussian (Gaussian Coherent State Amplitude)
  Definition: Symplectic eigenvalue scaling factor for Gaussian modulation
  Formula: Z ≈ √(V_A² + 2V_A) ≈ √(V_A(V_A + 2))
  Units: SNU^(1/2)
  Range: √(0.02) - √(40) ≈ 0.14 - 6.3 for typical V_A
  Physical Meaning: Amplitude of Eve's accessed Gaussian coherent state
  Use: Enters Holevo bound calculation in GM (Eq. 6, 9)

Z_M (Discrete Modulation Amplitude Coupling - M-PSK)
  Definition: Poisson-product coupling between adjacent constellation points
  Formula: Z_M² = Σₖ |α_k|^(3/2) · |α_{k+1}|^(-1/2)  [cyclic product]
  Units: SNU^(1/2)
  M-dependent: Different for BPSK, QPSK, 8-PSK, etc.
  Physical Meaning: Accounts for discrete nature of modulation in Holevo bound
  Use: Replaces Z_Gaussian in M-PSK Holevo bound (similar structure, different value)

Z* (M-QAM Effective Amplitude - Lower Bound)
  Definition: Lower bound on Eve's accessible coherent state amplitude in M-QAM
  Formula: Z* = 2√T · E[|α|²] - √(2T·ε_ch) · √(Var[|α|²])
           where expectation over M-QAM constellation
  Units: SNU^(1/2)
  Physical Meaning: Reduces Holevo bound due to binomial distribution averaging
  Use: Enters heterodyne Holevo bound (Eq. 17-19) for M-QAM

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
INFORMATION-THEORETIC VARIABLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

I_AB^hom (Mutual Information - Homodyne)
  Formula: I_AB^hom = 0.5 · log₂((V_A + 1 + χ_tot^hom) / (1 + χ_tot^hom)) [bits/pulse]
  Definition: Amount of classical information Alice can send to Bob via homodyne
  Units: bits/pulse (binary information per signal pulse)
  Range: 0 - 0.5 bits/pulse typically (0.5 factor due to single quadrature)
  Meaning: Higher I_AB → less noise → more secret key can be extracted
  Dependency: Increases with V_A (stronger signal), decreases with χ_tot (noise)

I_AB^het (Mutual Information - Heterodyne)
  Formula: I_AB^het = log₂((V_A + 1 + χ_tot^het) / (1 + χ_tot^het)) [bits/pulse]
  Definition: Mutual information with heterodyne detection (both quadratures)
  Units: bits/pulse
  Relationship: I_AB^het ≈ 2 × I_AB^hom (twice the information due to 2 quadratures)
  Usage: M-QAM protocol (Eq. 4, 16)

χ_BE (Eavesdropper Holevo Bound)
  Formula: χ_BE = Σᵢ G((λᵢ-1)/2) [bits/pulse]
           where G(x) = (x+1)log₂(1+x) - x·log₂(x)  [entropy function]
           and λᵢ are symplectic eigenvalues
  Definition: Upper bound on information accessible to eavesdropper Eve
  Units: bits/pulse
  Range: 0 - 1.0+ bits/pulse (typically 0.1-0.5 for satellite scenarios)
  Physical: Information-theoretic limit; Eve cannot access more than this
  Calculation:
    - GM Homodyne (Eq. 6, 9): χ_BE^GM from 4 symplectic eigenvalues
    - M-PSK Homodyne (Eq. 12 variant): Similar to GM, with Z_M instead of Z
    - M-QAM Heterodyne (Eq. 17-19): χ_BE^QAM from 3 symplectic eigenvalues
  Dependency: χ_BE increases with channel loss T (Eve's information improves with low SNR)

K_∞ (Asymptotic Secret Key Rate)
  Formula: K_∞ = β · I_AB - χ_BE [bits/pulse]
  Definition: Secret key generation rate in asymptotic (large N) limit
  Units: bits/pulse
  Physical Interpretation:
    - β·I_AB: Corrected mutual information (reconciliation factor applied)
    - χ_BE: Bound on Eve's information (subtracted for security)
    - Result: Net secret information rate
  Protocols:
    - GM (Eq. 4): K_∞^GM = β·0.5·log₂(...) - χ_BE^GM
    - PSK (Eq. 12): K_∞^PSK = β·0.5·log₂(...) - χ_BE^PSK
    - QAM (Eq. 16): K_∞^QAM = β·1.0·log₂(...) - χ_BE^QAM
  Constraints: K_∞ ≥ 0 (negative rates clipped to zero)

K_fin (Finite-Size Secret Key Rate)
  Formula: K_fin = f_rep · [(1-FER)·β·I_AB - χ_BE - Δn] [bits/second]
  Definition: Actual secret key rate achievable with finite block size
  Units: bits/second (or bits/s)
  Components:
    f_rep: Pulse repetition rate (Hz)
    1-FER: Reconciliation frame success rate
    β·I_AB: Corrected mutual information
    χ_BE: Eavesdropper bound
    Δn: Privacy amplification correction (Eq. 25)
  Difference from K_∞: Includes finite-size effects (corrections for real systems)
  Practical: This is the achievable key rate in satellite scenarios

λ_i (Symplectic Eigenvalues)
  Definition: Eigenvalues of covariance matrix in symplectic form
  Units: Dimensionless
  Count: 
    - Homodyne: 4 eigenvalues (λ₁, λ₂, λ₃, λ₄) for 2-mode system
    - Heterodyne: 3 independent eigenvalues (λ₁, λ₂, λ₃)
  Physical: Characterize Eve's quantum state; higher λ → more information for Eve
  Constraint: λᵢ ≥ 1 (physical states satisfy uncertainty principle)
  Usage: Holevo bound calculation χ_BE = Σ G((λᵢ-1)/2)

HOMODYNE DETECTION (GM & M-PSK Protocols)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Detection Scheme:
  - Measures ONE quadrature (X or P, alternating or randomized)
  - Uses local oscillator (LO) at signal frequency
  - Produces single value per pulse (one classical bit of info max)

Detector Noise Formula (Homodyne):
  χ_hom = (1 - η + ε_det) / η
  
  Breakdown:
    Numerator (1 - η + ε_det):
      - (1 - η) = inefficiency of detector
      - ε_det = excess intrinsic detector noise
    Denominator (η):
      - Scales everything by detector efficiency
    
  Example (η=0.6, ε_det=0.0135):
    χ_hom = (1 - 0.6 + 0.0135) / 0.6
          = (0.4 + 0.0135) / 0.6
          = 0.4135 / 0.6
          ≈ 0.6892 [SNU]

Total Receiver Noise (Homodyne):
  χ_tot^hom = χ_line + χ_hom/T
  
  Two contributions:
    1. χ_line: Thermal noise from channel loss (grows as 1/T)
    2. χ_hom/T: Detector noise scaled by loss (also grows as 1/T)
  
  At high loss (T=0.01):
    χ_tot^hom ≈ 99 + 0.689/0.01 ≈ 99 + 69 ≈ 168 [SNU] (dominated by detector!)
  
  At low loss (T=0.9):
    χ_tot^hom ≈ 0.11 + 0.689/0.9 ≈ 0.11 + 0.766 ≈ 0.87 [SNU]

Mutual Information (Homodyne):
  I_AB^hom = 0.5·log₂((V_A + 1 + χ_tot^hom) / (1 + χ_tot^hom))
  
  Factor of 0.5: Only ONE quadrature measured (half information vs heterodyne)

Detector Noise Formula (Heterodyne):
  χ_het = (1 + (1-η) + 2·ε_det) / η
  
  Breakdown:
    Numerator:
      - 1 : vacuum state contribution (constant)
      - (1-η) : detector inefficiency
      - 2·ε_det : TWICE the excess noise (X AND P quadratures both add noise)
    Denominator (η):
      - Scales by detector efficiency
    
  Key difference: Factor of 2 on ε_det (two independent measurements)
  
  Example (η=0.6, ε_det=0.0135):

          = (1 + 0.4 + 0.027) / 0.6
          = 1.427 / 0.6
          ≈ 1.3783 [SNU]
  
  Relationship to homodyne:
    χ_het ≈ 2.0 × χ_hom (approximately doubles, not exactly due to constant term)
    χ_het/χ_hom = 1.3783 / 0.6892 ≈ 2.0

  χ_tot^het = χ_line + χ_het/T
  
  Structure identical to homodyne, but with χ_het instead of χ_hom:
