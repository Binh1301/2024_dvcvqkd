Scope: add a saved-data plotting module and tests; no simulations, optimization,
parameter changes, historical result changes, commits or pushes.

Reuse propulsion_power/EnergyModel, load_config/build_scenario, verify_results,
SKRLookup and finite_key. Preserve original producers to keep old hashes valid.

1. Source-verified rotor power and numerical lower convex envelope.

3. Spatial asymptotic SKR samples, with explicit evidence scope.
4. Selected P1 trajectories; 5. selected P2 trajectories.
6. Cumulative propulsion energy for both objectives.
7. P2 accumulated signals, asymptotic contribution, terminal-block penalty, key.
8. P1 average rate and P2 total estimated key comparisons.
9. Recorded runtime, Python allocation peak and sampled process RSS.
10. Recorded energy, threshold, waypoint-spacing and label-cap sensitivities.

Default command uses unchanged configs/paper.yaml and figures/paper/. A missing
or inadmissible input writes BLOCKED manifests and no placeholder scientific
images. Figure 1 can be READY as a model illustration independent of a mission;
this does not promote paper-mode or security status. Every other figure requires
the same verified saved-run configuration and source/readiness evidence.

Explicit --exploratory accepts existing synthetic or unvalidated results only
with an unmistakable EXPLORATORY label/caption/manifest. No exploratory exports
are generated by default. Unit rendering tests use existing saved demo results.

Use 3.5/7.16 inch column widths, vector PDF and 600 dpi PNG, serif typography,
gray/blue/orange/green algorithms, distinct line styles and bar hatches. Source
version and numerical/data qualifications travel with each English caption.

Tests first: blocked gates, source model values, style and physical width, exact
mask relationship, trajectory endpoints, accumulated finite-size quantities,
recorded runtime/memory, raw SKR scale and source hashes, sensitivity arithmetic,
tampering, missing measurements and refusal to overwrite outputs. Run the full
suite and inspect actual exports before final delivery.
