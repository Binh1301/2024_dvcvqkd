## 4. Finite-size configuration

Reference: Ismail et al., IEEE Communications Letters 2025.

- N_full = 1e8.
- Key allocation fraction = 0.8.
- epsilon_PE = 1e-8.
- epsilon_EC = 1e-8.
- epsilon_PA = 1e-8.
- epsilon_total = 3e-8.
- f_s = 1e5 uses/s.
- m0 = 0.8 × f_s × Delta_t = 800000 signals/slot.

For a prefix of K slots:

n_K = m0 × sum(z_k)

S_K = m0 × sum(z_k × R_clear(q_k))

ell_K = max(0, S_K - 7 × sqrt(n_K × log2(2/epsilon_total)))

P1 = max over feasible K of ell_K / (K × Delta_t).

P2 = max over feasible K of ell_K.

Use the existing finite-size proxy implementation if consistent with these definitions.

Apply the finite-size penalty once per evaluated prefix, not once per slot.

Keep emitted-signal count, key allocation fraction, and cloud erasure separately documented.

This is a finite-size performance approximation for MB-shaped QAM, not a composable-security proof.
